# Findings are predefined per case; releasing only toggles visibility

A case carries a fixed, predefined list of findings (name + optional note in V1; images/file attachments planned for V2). Doctors cannot invent findings live mid-case: the cockpit is a checklist, and releasing flips a finding visible to viewers while un-releasing hides it again (used only to correct mistakes; unreleased findings vanish from viewers without trace). We chose this over a free-form stream created live because rehearsed roleplays follow a script the doctors know in advance, and a checklist turns "release at the right moment" into a single deliberate tap.
